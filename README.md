# fountain-rs

A rewrite of the original Objective-C Fountain library in Rust.

| Crate | Description |
|---|---|
| [fountain-core](crates/fountain-core) | Fountain markup parser and types |
| [fountain-render](crates/fountain-render) | Rendering engine for parsed Fountain scripts |
| [fountain-cli](crates/fountain-cli) | Convert `.fountain` to `.pdf`/`.fdx`, live preview |
| [fountain-app](crates/fountain-app) | Web app for writing screenplays using Fountain|
